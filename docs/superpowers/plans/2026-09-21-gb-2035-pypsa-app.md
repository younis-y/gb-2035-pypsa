# gb-2035-pypsa Front End, Docker and Docs Implementation Plan (phase 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the presentation layer the spec's phase 3 calls for: a read-only Streamlit
explorer with a zone map over the committed results, a container image published to GHCR, and
the documentation that points a reader at both.

**Architecture:** A new `src/gb2035/app/` package: pure readers over the committed artefacts
(`data.py`), pure Plotly figure builders (`charts.py`, `mapview.py`), a shared palette
(`palette.py`) and a thin Streamlit script (`main.py`) that wires five tabs together. The app
imports nothing from `gb2035.model` and never touches PyPSA, linopy or HiGHS; an architecture
test enforces that. A new `gb2035 app` CLI command shells out to `streamlit run` on the module
path. A multi-stage `Dockerfile` installs the project with `uv sync --frozen --no-dev --extra
app` and serves the same script; the image is built, linted and smoke-tested in GitHub Actions
only, because Docker cannot run on the development machine.

**Tech Stack:** Python 3.13, uv + hatchling, streamlit>=1.45 (1.64 in the lock),
plotly>=5.24 (7.1 in the lock, so `go.Choroplethmap`/`go.Scattermap`, no Mapbox token),
kaleido>=1.0 (dev only, for the committed README map PNG), pandas>=3, pytest with
`streamlit.testing.v1.AppTest`, ruff, mypy strict, Docker Buildx, hadolint, GHCR.

**Spec:** `docs/superpowers/specs/2026-09-18-gb-2035-pypsa-design.md` (sections 12, 14 and 16
phase 3). Phases 1 and 2 were delivered by
`docs/superpowers/plans/2026-09-18-gb-2035-pypsa-core.md`; nothing in that plan is re-planned
here.

- The app is read-only. It may open `results/summary.csv`, `results/<scenario>/*.csv`,
  `results/<scenario>/run_meta.json`, `config/scenarios.yaml`, `config/assumptions.yaml`,

## Decisions (the spec is silent or superseded)

1. **Plotly, not folium.** Spec section 12 names a folium choropleth. This plan uses Plotly
   (`go.Choroplethmap` + `go.Scattermap`, MapLibre, no token) for every chart and the map, so the
   app carries one charting library instead of three. `folium` and `streamlit-folium` are removed
   from the `app` extra. Recorded again in `docs/app.md`.
2. **Tabs, not pages.** One script with `st.tabs` for the five views. `AppTest` executes every
   tab body in a single run, so the smoke tests cover all five views in two app runs.
3. **Five views, not the spec's Dispatch page.** Spec section 12 lists a Dispatch page with a
   week picker. Its input, `results/<scenario>/dispatch_hourly.parquet`, is git-ignored (`.gitignore`
   line `results/**/dispatch_hourly.parquet`), so a fresh clone and the container have no data for
   it. The five views built here are Overview, Map, Capacity and energy, Teesside hydrogen,
   Assumptions. `docs/app.md` records the omission and why.
4. **Map metrics: new-build capacity, total capacity, demand-weighted price.** Per-zone
   curtailment does not exist in the committed extracts: `results/<scenario>/curtailment.csv` is by
   carrier for the whole system, and recomputing it per zone needs `network.nc`, which is
   git-ignored and would require re-solving every scenario. The Map view says so in a caption and
   sends the reader to the Capacity and energy view for the system-wide split.
5. **`data/derived/zones.geojson` is already committed** (268 KB, 23 features keyed on
   `properties.Name_1`: 20 land zones plus `DOGGER_BANK`, `HORNSEA`, `EAST_ANGLIA`; verified with
   `git ls-files data/derived`). No simplified copy is added. Zone centroids for the corridor lines
   come from the committed `data/derived/buses.csv` (`name,y,x,v_nom,carrier`), which is the
   model's own bus coordinate table.
6. **Interconnector legs are excluded from zone capacity.** `capacities.csv` lists `ic * import`
   and `ic * export` at full capacity each, so summing them would double-count 19.4 GW. The zone
   metrics drop carriers `import` and `export`, as the README limitation already flags.
7. **One image, two entry points.** `CMD` serves the app, but the `gb2035` CLI stays on the
   image's PATH, so spec section 14's "run `gb2035 run --scenario test` inside it" is still the
   CI smoke test.
8. **No documentation-site generator.** The spec's architecture (section 8) and CI section (14)
   list Markdown files under `docs/` and two workflows; no MkDocs, Sphinx or Pages step is
   specified anywhere. `docs/app.md` is a Markdown page like its neighbours.
9. **The static README map is exported with `map_style="white-bg"`.** The zone polygons carry the
   geography, the export needs no tile server at render time, and no OSM tiles are redistributed
   in the repository.

`src/gb2035/app/data.py`:
```python
"""Every read the app makes, and the caching that keeps a rerun cheap.

The `read_*` functions are pure: a path in, a DataFrame or dict out, no Streamlit involved, so
they are unit-testable on their own. The `load_*` names are the same functions wrapped in
`st.cache_data`, assigned rather than decorated so the pure function stays importable and mypy
strict stays happy whether or not the installed Streamlit ships type information.
"""

from __future__ import annotations

from collections.abc import Sequence
from pathlib import Path

DEFAULT_SCENARIO = "cap5"
MARKER_FILES: tuple[str, ...] = ("config/scenarios.yaml", "results/summary.csv")


def find_project_root(start: Path) -> Path:
    """The nearest directory at or above `start` that holds every file in `MARKER_FILES`."""
    for candidate in (start, *start.parents):
        if all((candidate / rel).exists() for rel in MARKER_FILES):
            return candidate
    msg = f"no gb2035 project root at or above {start}: looked for {', '.join(MARKER_FILES)}"
    raise FileNotFoundError(msg)


def resolve_root(argv: Sequence[str], start: Path) -> Path:
    """`--root <path>` from `streamlit run main.py -- --root <path>`, else discovery.

    Streamlit passes everything after `--` through to the script, and `AppTest` passes nothing,
    so discovery is what runs under test and inside the container.
    """
    if "--root" in argv:
        index = argv.index("--root")
        if index + 1 < len(argv):
            return Path(argv[index + 1]).resolve()
    return find_project_root(start)
```

```python
    ),
    Headline(
        "emissions_mt",
        "Emissions",

    ),
    Headline(

        "Dual of the CO2 cap. Zero where the cap is slack or absent.",

def headline_values(row: pd.Series) -> list[tuple[str, str, str]]:
    """(label, formatted value, note) for each headline metric of one summary row."""
    return [(h.label, h.fmt.format(float(row[h.column])), h.note) for h in HEADLINES]
```

```python
@dataclass(frozen=True)
class MapMetric:
    """One choropleth colour source: which `zone_metrics` column, and its unit."""

    column: str
    unit: str


MAP_METRICS: dict[str, MapMetric] = {
    "New-build capacity (GW)": MapMetric("new_build_gw", "GW"),
    "Total generation capacity (GW)": MapMetric("total_capacity_gw", "GW"),
    "Demand-weighted price (GBP/MWh)": MapMetric("price_gbp_per_mwh", "GBP/MWh"),
}
# `capacities.csv` lists `ic * import` and `ic * export` at full capacity each, so summing both
# legs would double-count the 19.4 GW of physical interconnection (README, "What this model
# does not claim"). Zone capacity counts generation and storage only.
TRADE_CARRIERS: frozenset[str] = frozenset({"import", "export"})
PRICE_METRIC = "demand_weighted_price_gbp_per_mwh"


def read_zone_geojson(root: Path) -> dict[str, Any]:
    """The committed zone polygons: 20 land zones plus the three offshore lease areas."""
    geojson: dict[str, Any] = json.loads((root / "data" / "derived" / "zones.geojson").read_text())
    return geojson


def read_bus_coordinates(root: Path) -> pd.DataFrame:
    return pd.read_csv(root / "data" / "derived" / "buses.csv")


def _as_bool(series: pd.Series) -> pd.Series:
    """`existing` is bool in the committed CSVs; coerce a string column without lying."""
    if series.dtype == bool:
        return series
    return series.astype(str).str.strip().str.lower().eq("true")


def zone_metrics(capacities: pd.DataFrame, duals: pd.DataFrame) -> pd.DataFrame:
    """One row per land zone: new build, total capacity and the demand-weighted price."""
    built = capacities[
        capacities["component"].isin(["Generator", "StorageUnit"])
        & capacities["zone"].isin(LAND_ZONES)
        & ~capacities["carrier"].isin(TRADE_CARRIERS)
    ]
    existing = _as_bool(built["existing"])
    total = built.groupby("zone")["p_nom_opt"].sum() / 1e3
    new = built[~existing].groupby("zone")["p_nom_opt"].sum() / 1e3
    price = duals[duals["metric"] == PRICE_METRIC].set_index("zone")["value"]
    index = pd.Index(list(LAND_ZONES), name="zone")
    out = pd.DataFrame(index=index)
    out["zone_name"] = [ZONE_LABELS[zone] for zone in index]
    out["new_build_gw"] = new.reindex(index).fillna(0.0)
    out["total_capacity_gw"] = total.reindex(index).fillna(0.0)
    out["price_gbp_per_mwh"] = price.reindex(index)
    return out.reset_index()


def corridor_flows(flows: pd.DataFrame, buses: pd.DataFrame) -> pd.DataFrame:
    """`flows.csv` with each corridor's endpoints and midpoint taken from the bus coordinates."""
    coords = buses.set_index("name")
    out = flows.copy()
    out["net_twh"] = out["twh_forward"] - out["twh_reverse"]
    out["lon0"] = out["bus0"].map(coords["x"])
    out["lat0"] = out["bus0"].map(coords["y"])
    out["lon1"] = out["bus1"].map(coords["x"])
    out["lat1"] = out["bus1"].map(coords["y"])
    out["lon_mid"] = (out["lon0"] + out["lon1"]) / 2.0
    out["lat_mid"] = (out["lat0"] + out["lat1"]) / 2.0
    out["label"] = out["bus0"] + " to " + out["bus1"]
    return out.dropna(subset=["lon0", "lat0", "lon1", "lat1"]).reset_index(drop=True)
```

```python
"""Plotly figures for the app: a DataFrame in, a `go.Figure` out, no Streamlit involved."""

from __future__ import annotations

import pandas as pd
import plotly.graph_objects as go
from plotly.subplots import make_subplots

from gb2035.app.palette import (
    BASELINE,
    BLUE,
    CAP_ORDER,
    CARRIER_COLOURS,
    FONT_FAMILY,
    GRIDLINE,
    INK_MUTED,
    INK_PRIMARY,
    ORANGE,
    SURFACE,
    TECH_SERIES,
)

CHART_HEIGHT = 420


def _style(fig: go.Figure, height: int = CHART_HEIGHT) -> go.Figure:
    fig.update_layout(
        height=height,
        paper_bgcolor=SURFACE,
        plot_bgcolor=SURFACE,
        font={"family": FONT_FAMILY, "color": INK_PRIMARY, "size": 13},
        margin={"l": 60, "r": 20, "t": 50, "b": 40},
        legend={"orientation": "h", "yanchor": "top", "y": -0.15, "x": 0},
        hovermode="closest",
    )
    fig.update_xaxes(gridcolor=GRIDLINE, linecolor=BASELINE, zeroline=False)
    fig.update_yaxes(gridcolor=GRIDLINE, linecolor=BASELINE, zeroline=False)
    return fig


def cap_scenarios(summary: pd.DataFrame) -> pd.DataFrame:
    """The cap sweep only, ordered by realised emissions.

    `uncapped` is not a cap at all and lands mid-sweep on emissions, so ordering by cap name
    makes the line double back on itself (`report/figures.py` makes the same choice).
    """
    df = summary[summary["scenario"].isin(CAP_ORDER)].copy()
    return df.sort_values("emissions_mt", ascending=False).reset_index(drop=True)


def cost_and_shadow_price_figure(summary: pd.DataFrame, highlight: str) -> go.Figure:
    """System cost and the CO2 dual against realised emissions, with one scenario picked out."""
    df = cap_scenarios(summary)
    fig = make_subplots(
        rows=1,
        cols=2,
        subplot_titles=("System cost", "Shadow carbon price"),
        horizontal_spacing=0.12,
    )
    panels = (
        (1, "total_cost_gbp_bn_per_yr", "bn GBP/yr", BLUE),
        (2, "shadow_carbon_price_gbp_per_t", "GBP/t", ORANGE),
    )
    for col, column, unit, colour in panels:
        fig.add_trace(
            go.Scatter(
                x=df["emissions_mt"],
                y=df[column],
                mode="lines+markers",
                name=unit,
                showlegend=False,
                line={"color": colour, "width": 2},
                marker={"size": 8, "color": colour},
                customdata=df[["scenario"]].to_numpy(),
                hovertemplate=(
                    "<b>%{customdata[0]}</b><br>%{x:.1f} MtCO2/yr<br>"
                    f"%{{y:.2f}} {unit}<extra></extra>"
                ),
            ),
            row=1,
            col=col,
        )
    chosen = df[df["scenario"] == highlight]
    for col, column, _unit, colour in panels:
        if chosen.empty:
            continue
        fig.add_trace(
            go.Scatter(
                x=chosen["emissions_mt"],
                y=chosen[column],
                mode="markers",
                showlegend=False,
                hoverinfo="skip",
                marker={"size": 16, "color": colour, "line": {"width": 2, "color": INK_PRIMARY}},
            ),
            row=1,
            col=col,
        )
    fig.update_xaxes(title_text="Emissions (MtCO2/yr)", autorange="reversed")
    fig.update_yaxes(title_text="bn GBP/yr", row=1, col=1)
    fig.update_yaxes(title_text="GBP/t", row=1, col=2)
    return _style(fig)


def capacity_mix_figure(summary: pd.DataFrame) -> go.Figure:
    """Installed capacity by technology across the cap sweep."""
```

```python
"""The zone map: a choropleth over the 20 land zones, corridor flows on top.

`go.Choroplethmap` and `go.Scattermap` are the MapLibre traces, so nothing here needs a Mapbox
token. `map_style="open-street-map"` fetches tiles in the browser; the static README export
passes `map_style="white-bg"` so it renders with no tile server at all.
"""

from __future__ import annotations

from typing import Any

import pandas as pd
import plotly.graph_objects as go

from gb2035.app.palette import (
    BASELINE,
    BLUE,
    FONT_FAMILY,
    GRIDLINE,
    INK_PRIMARY,
    ORANGE,
    RED,
    SURFACE,
)
from gb2035.data.zones import OFFSHORE_ZONES, ZONE_LABELS

# The Teesside industrial cluster, the site the `Teesside H2` bus stands for. A location, not a
# model result; the same coordinate the zone assignment test uses for Teesside.
TEESSIDE_LATLON: tuple[float, float] = (54.60, -1.15)
GB_CENTRE: dict[str, float] = {"lat": 55.3, "lon": -3.2}
GB_ZOOM = 4.2
MAP_HEIGHT = 760
COLOURSCALE: list[list[Any]] = [[0.0, "#eef4fc"], [0.5, "#8ab4e8"], [1.0, BLUE]]
ZONE_HOVER = (
    "<b>%{customdata[0]}</b> (%{location})<br>"
    "New build %{customdata[1]:.2f} GW<br>"
    "Total capacity %{customdata[2]:.2f} GW<br>"
    "Demand-weighted price %{customdata[3]:.2f} GBP/MWh"
    "<extra></extra>"
)


def line_widths(net_twh: pd.Series) -> pd.Series:
    """Corridor line width, 1 to 6 points, scaled by net annual energy."""
    scale = float(net_twh.abs().max()) if len(net_twh) else 0.0
    if scale <= 0:
        return pd.Series(1.5, index=net_twh.index, dtype=float)
    return 1.0 + 5.0 * net_twh.abs() / scale


def zone_choropleth(
    geojson: dict[str, Any],
    metrics: pd.DataFrame,
    flows: pd.DataFrame,
    *,
    metric: str,
    metric_label: str,
    hover_unit: str,
    map_style: str = "open-street-map",
) -> go.Figure:
    """Land zones coloured by `metric`, corridors as lines, the Teesside node marked."""
    customdata = metrics[
        ["zone_name", "new_build_gw", "total_capacity_gw", "price_gbp_per_mwh"]
    ].to_numpy()
    fig = go.Figure(
        go.Choroplethmap(
            geojson=geojson,
            featureidkey="properties.Name_1",
            locations=metrics["zone"],
            z=metrics[metric],
            customdata=customdata,
            hovertemplate=ZONE_HOVER,
            colorscale=COLOURSCALE,
            marker={"opacity": 0.82, "line": {"width": 1, "color": SURFACE}},
            colorbar={"title": {"text": f"{metric_label}<br>({hover_unit})"}, "thickness": 14},
            name="",
        )
    )
    # The offshore lease areas carry no zone metric: their generators are modelled at the
    # landing buses (Z8, Z12), so they are context, not data.
    fig.add_trace(
        go.Choroplethmap(
            geojson=geojson,
            featureidkey="properties.Name_1",
            locations=list(OFFSHORE_ZONES),
            z=[0.0] * len(OFFSHORE_ZONES),
            colorscale=[[0.0, GRIDLINE], [1.0, GRIDLINE]],
            showscale=False,
            marker={"opacity": 0.35, "line": {"width": 1, "color": BASELINE}},
            text=[ZONE_LABELS[zone] for zone in OFFSHORE_ZONES],
            hovertemplate="<b>%{text}</b><br>offshore lease area<extra></extra>",
            name="",
        )
    )
    widths = line_widths(flows["net_twh"])
    for position, (_, corridor) in enumerate(flows.iterrows()):
        fig.add_trace(
            go.Scattermap(
                lat=[corridor["lat0"], corridor["lat1"]],
                lon=[corridor["lon0"], corridor["lon1"]],
                mode="lines",
                line={"width": float(widths.iloc[position]), "color": ORANGE},
                hoverinfo="skip",
                showlegend=False,
                name="",
            )
        )
    fig.add_trace(
        go.Scattermap(
            lat=flows["lat_mid"],
            lon=flows["lon_mid"],
            mode="markers",
            marker={"size": 7, "color": ORANGE},
            customdata=flows[
                ["label", "p_nom_total_mw", "net_twh", "max_utilisation", "hours_congested_share"]
            ].to_numpy(),
            hovertemplate=(
                "<b>%{customdata[0]}</b><br>"
                "Capacity %{customdata[1]:,.0f} MW<br>"
                "Net flow %{customdata[2]:.2f} TWh<br>"
                "Peak utilisation %{customdata[3]:.0%}<br>"
                "Hours at capacity %{customdata[4]:.1%}"
                "<extra></extra>"
            ),
            showlegend=False,
            name="",
        )
    )
    fig.add_trace(
        go.Scattermap(
            lat=[TEESSIDE_LATLON[0]],
            lon=[TEESSIDE_LATLON[1]],
            mode="markers",
            marker={"size": 13, "color": RED},
            hovertemplate="<b>Teesside H2 node</b><br>hydrogen bus, coupled to Z7<extra></extra>",
            showlegend=False,
            name="",
        )
    )
    fig.update_layout(
        map={"style": map_style, "center": GB_CENTRE, "zoom": GB_ZOOM},
        height=MAP_HEIGHT,
        margin={"l": 0, "r": 0, "t": 0, "b": 0},
        paper_bgcolor=SURFACE,
        font={"family": FONT_FAMILY, "color": INK_PRIMARY, "size": 13},
    )
    return fig
```

```python
from pathlib import Path

from typer.testing import CliRunner

from gb2035 import cli
from gb2035.cli import app

runner = CliRunner()


class FakeRun:
    def __init__(self, returncode: int = 0):
        self.returncode = returncode
        self.calls: list[list[str]] = []

    def __call__(self, command, **kwargs):
        self.calls.append(list(command))
        return subprocess.CompletedProcess(command, self.returncode)


def test_app_command_runs_streamlit_on_the_module(repo_root: Path, monkeypatch):
    fake = FakeRun()
    monkeypatch.setattr(cli.subprocess, "run", fake)
    result = runner.invoke(app, ["app", "--root", str(repo_root)])
    assert result.exit_code == 0, result.stdout
    command = fake.calls[0]
    assert command[:4] == [sys.executable, "-m", "streamlit", "run"]
    assert command[4].endswith(str(Path("gb2035") / "app" / "main.py"))
```

```python
@app.command("app-map")
def app_map_cmd(
    root: RootOpt = Path(),
    scenario: ScenarioOpt = "cap5",
    metric: Annotated[
        str, typer.Option("--metric", help="A zone_metrics column, e.g. new_build_gw.")
    ] = "new_build_gw",

    width: Annotated[int, typer.Option("--width")] = 900,
    height: Annotated[int, typer.Option("--height")] = 1150,
) -> None:
    """Render the app's map view to a PNG for the README (needs the dev group's kaleido)."""
    from gb2035.app.data import (
        MAP_METRICS,
        corridor_flows,
        read_bus_coordinates,
        read_scenario_table,
        read_zone_geojson,
        zone_metrics,
    )
    from gb2035.app.mapview import zone_choropleth

    paths = ProjectPaths(root.resolve())
    label = next((name for name, m in MAP_METRICS.items() if m.column == metric), None)
    if label is None:
        known = sorted(m.column for m in MAP_METRICS.values())
        console.print(f"[red]unknown metric {metric!r}; known: {known}[/red]")
        raise typer.Exit(code=2)
    figure = zone_choropleth(
        read_zone_geojson(paths.root),
        zone_metrics(
            read_scenario_table(paths.root, scenario, "capacities"),
            read_scenario_table(paths.root, scenario, "duals"),
        ),
        corridor_flows(
            read_scenario_table(paths.root, scenario, "flows"), read_bus_coordinates(paths.root)
        ),
        metric=metric,
        metric_label=label,
        hover_unit=MAP_METRICS[label].unit,
        # No tiles: the export must not depend on a tile server at render time.
        map_style="white-bg",
    )
    target = out or (paths.root / "docs" / "figures" / "app_map.png")
    target.parent.mkdir(parents=True, exist_ok=True)
    figure.write_image(target, format="png", width=width, height=height, scale=2)
    console.print(f"{target} written ({target.stat().st_size / 1024:.0f} KB)")
```

````markdown
# The results explorer

A read-only Streamlit app over the committed artefacts. It does not build or solve a network,
it writes nothing, and it holds no numbers of its own: every figure and metric is read at
runtime from a file in this repository, so the app cannot disagree with `results/`.

docker run -p 8501:8501 ghcr.io/younis-y/gb-2035-pypsa:latest
```

The scenario selector in the sidebar lists every directory under `results/` that carries a
`summary_row.csv`, in the order `results/summary.csv` uses. The description beside it comes from
`config/scenarios.yaml`.

## Overview

Five headline metrics for the selected scenario, read from `results/summary.csv`: system cost
(bn GBP/yr), emissions (MtCO2/yr), the shadow carbon price (GBP/t, the dual of the CO2 cap),
net interconnector imports (TWh) and the share of available wind and solar that was curtailed.

Below them, system cost and the shadow carbon price against realised emissions across the cap
sweep, with the selected scenario ringed. The series is ordered by emissions rather than by cap
name, because `uncapped` is not a cap and lands mid-sweep; ordering by name makes the line
double back on itself. The footer line comes from `results/<scenario>/run_meta.json`: PyPSA
version, commit, snapshot count, resolution, solver and solve time.

## Map

The 20 land zones from `data/derived/zones.geojson`, shaded by one of three metrics:

| Metric | Built from |
|---|---|
| New-build capacity (GW) | `results/<scenario>/capacities.csv`, generation and storage the optimiser added (`existing` is false) |
| Total generation capacity (GW) | the same file, every generation and storage row |
| Demand-weighted price (GBP/MWh) | `results/<scenario>/duals.csv`, `demand_weighted_price_gbp_per_mwh` |

Interconnector import and export legs are excluded from both capacity metrics: `capacities.csv`
lists each leg at the full interconnector capacity, so summing them would double-count the
19.4 GW of physical interconnection.

The 31 inter-zone corridors are drawn as lines between the zone bus coordinates in
`data/derived/buses.csv`, their width scaled by net annual energy from
`results/<scenario>/flows.csv`. Hovering the midpoint marker gives the corridor's capacity, net
flow, peak utilisation and the share of hours it sat at capacity. The three offshore lease areas
are outlined in grey and carry no metric, because their generators are modelled at their landing
buses (Z8 and Z12). The red marker is the `Teesside H2` bus, coupled to Z7.

Curtailment is not on this map. `results/<scenario>/curtailment.csv` is a whole-system split by
carrier, and a per-zone version would need `network.nc`, which is git-ignored, so it is not
available to a fresh clone or to the container. The Capacity and energy view shows the
system-wide figure instead.

## Capacity and energy

Installed capacity by technology across the cap sweep, stacked, from `results/summary.csv`;
then annual electricity by carrier for the selected scenario from
`results/<scenario>/energy.csv`, electricity rows only. Exports and electrolysis are withdrawals
and plot negative. The hydrogen rows (`bus_carrier == "H2"`) are measured in hydrogen and are
never added to the power rows. Below the charts, `results/<scenario>/curtailment.csv`: available
energy, used energy and the curtailed share for onshore wind, offshore wind and solar.

## Teesside hydrogen

`results/<scenario>/hydrogen.csv` in full: electrolysis capacity and utilisation, green
hydrogen, store size, hydrogen turbine capacity, hydrogen to power, blue hydrogen and the
industrial demand. Underneath it, `docs/figures/teesside_hydrogen.png`, the cross-scenario green
against blue split that `gb2035 report` writes.

## Assumptions

`config/assumptions.yaml` as a filterable table: key, value, unit, confidence and source. Every
row carries a source URL and one of three confidence tags (published, derived, assumption).
Technology capex, fixed and variable O&M, efficiencies and lifetimes are not here: they are in
`data/derived/costs_2035_gb.csv`, one source per row.

## Two deviations from the design spec

- **Plotly, not folium.** Spec section 12 named a folium choropleth. The app uses Plotly's
  MapLibre traces (`Choroplethmap`, `Scattermap`) so that one charting library covers the charts
  and the map and the map needs no Mapbox token.
- **No Dispatch view.** Spec section 12 listed a Dispatch page with a week picker. Its input,
  `results/<scenario>/dispatch_hourly.parquet`, is deliberately git-ignored, so a fresh clone
  and the published image have no data for it. Regenerate it with
  `uv run gb2035 run --scenario <name>` if you want the hourly series locally.
````
